# garces_lab1a discussion

In this lab experiment, I developed the UI for Facebook News Feed in Flutter using proper file structuring in three major folders namely `screens`, `widgets`, and `assets`. In `newsfeed_card.dart`, I used dynamic images with the help of a conditional `hasImage` that would display the image if `true` else nothing. Moreover, the profile icon was updated to `CircleAvatar` and action button to widget-based. In doing this experiment, I got to learn about proper structuring of Flutter project and how to use `flutter_screenutil`.
